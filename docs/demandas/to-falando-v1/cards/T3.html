Origem

Demanda to-falando-v1: RF-4 (o host redefine a senha por comando no servidor) e CA-7.

Padrão

Técnica §6: redefinir a senha revoga as sessões. Scripts do servidor em server/src/cli.

Implementação (04/11/2026, commit 5b1211b)

  • Comando: npm run redefinir-senha -w server -- <usuario> (no Docker: docker compose exec server npm run redefinir-senha -- <usuario>).
  • Entrada: senha e confirmação pedidas sem eco no terminal, ou as duas primeiras linhas da entrada padrão; nunca por argumento.
  • Efeito: grava o novo hash scrypt e apaga as sessões da conta na mesma transação.
  • Saída: 0 ok, 1 uso/senha inválida, 2 usuário não encontrado (inclusive removido no meio), 3 erro interno, 130 cancelado (Ctrl+C, Ctrl+D ou entrada incompleta).
  • Pendência registrada na T4: conexões em tempo real abertas precisam cair quando a sessão é revogada por outro processo.

Testes

server/test/redefinir-senha.test.ts: CA-7 com o comando em outro processo (senha nova entra, antiga 401, token antigo 401); uso errado, inexistente, senha curta, confirmação diferente, cancelamento, conta removida. Suíte: 72 testes passando; lint e build verdes.
